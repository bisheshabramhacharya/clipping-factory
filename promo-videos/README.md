# Clipping Factory promo videos

Three original 1080x1920 Remotion introductions built from the supplied product screenshots.

```bash
npm install
npm run music
npm run studio
npm run render
```

The three compositions are `ClippingFactory-Editorial`, `ClippingFactory-Momentum`, and `ClippingFactory-Quiet`. Music is synthesized locally by `scripts/generate-music.mjs` and is original to these videos.
