# Reference panel

Seven published screenshots from three other products, kept outside this
repository's own UI so a comparative review has something real to anchor on.
`manifest.json` carries the source URL of every file; `panel` is not a design
system and nothing here should be copied into `static/`.

- **T3 Code** (1 file): desktop app, from the product site. The GitHub README
  has no inline product screenshots at the time of writing, so the README rule
  resolves to the screenshot the vendor publishes for the same app.
- **Opus Clip** (3 files): clip editor, a finished vertical clip, and the clip
  grid.
- **Descript** (3 files): editor, Underlord prompt, Underlord chat edit.

All files were converted to PNG so every viewer in the harness reads them the
same way. The manifest records any resizing. These are third-party assets used
for internal comparison only; do not redistribute them as part of the product.
